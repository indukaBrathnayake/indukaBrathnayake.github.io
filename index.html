Overview

Project Background & Objectives

This final year project focuses on developing an intelligent protection system for modern power networks that integrate distributed generation. In Phase 1, work is centered on software and simulation to model standard IEEE test systems. By simulating diverse fault conditions, we collect comprehensive voltage and current time-series data to train an advanced Hybrid CNN-LSTM deep learning model. In Phase 2, that trained model is deployed on embedded hardware to build a physical relay.
