Overview

What is Project NOAA?

NOAA weather satellites (NOAA-15, NOAA-18, NOAA-19) continuously transmit weather imagery on 137 MHz using the Automatic Picture Transmission (APT) format. This project involved building a ground station to receive those signals, decode the audio, and reconstruct the satellite weather images.

How It Works

System Architecture

The system pipeline consists of four main stages:

  1. Antenna & SDR Reception — A V-dipole or turnstile antenna at 137 MHz feeds into an RTL-SDR dongle
  2. Signal Demodulation — Wide-FM demodulation extracts the APT audio subcarrier using SDR# or GNU Radio
  3. APT Decoding — The 2400 baud APT signal is decoded using WXtoImg or a custom Python decoder
  4. Image Reconstruction — The decoded data is assembled into a visible + infrared weather image
